# 📝 Python To-Do List App

A simple command-line To-Do List application built with Python.

## Features

* Add tasks
* View tasks
* Delete tasks
* Input validation
* Continue or exit the application

## Technologies

* Python

## How to Run

Make sure Python is installed on your computer.

Run the program with:

```bash
python main.py
```
